# GreenHarvest Farms

A premium, modern agriculture business website built with Next.js 14 (App Router), TypeScript, and Tailwind CSS.

## Features
- **Modern Design**: High-quality aesthetics with natural green and earth-tone accents.
- **Micro-animations**: Smooth scrolling and entrance animations via Framer Motion.
- **SEO Optimized**: Fully prepared with metadata and semantic HTML.
- **Responsive**: Mobile-first design that looks great on all devices.
- **Production Ready**: Clean code structure following strict constraints.

## Tech Stack
- **Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: [Google Fonts (Outfit & Playfair Display)](https://fonts.google.com/)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure
- `/app`: Main application routes (layout, pages).
- `/components`: Reusable UI components (Navbar, Footer).
- `/sections`: Thematic page sections (Hero, About, Produce, etc.).
- `/lib`: Utility functions and shared logic.
- `/styles`: Global styles and Tailwind configuration.
- `/public`: Static assets (Logo placeholders, etc.).
